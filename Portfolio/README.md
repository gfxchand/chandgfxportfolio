# Chandgfx Portfolio

A premium, minimalist portfolio website for a Graphic Designer and Personal Branding Expert specializing in LinkedIn branding, founder visuals, social media creatives, and premium brand systems.

## 🎨 Design Philosophy

This portfolio is built on a "Swiss-inspired" design system, prioritizing clean whitespace, strong visual hierarchy, editorial typography (Poppins), and smooth micro-animations. It features a modern aesthetic with deep blue accents (`#005aff`) on a subtle grid background, utilizing elegant rounded cards and glassmorphism for a high-end, founder-focused vibe.

## ✨ Features

- **Custom Design System**: Utilizes a fully customized CSS variable system for consistent theming and easy updates.
- **Scroll Animations**: Implemented using the native Intersection Observer API in Vanilla JS to trigger subtle `.reveal-up` and `.reveal-scale` animations as elements enter the viewport.
- **Responsive Layouts**: Fully responsive grid systems including a Masonry layout for the "Selected Work" section and a timeline layout for the "Process" section.
- **Interactive Testimonials**: A custom drag-to-scroll carousel built with Vanilla JS for a smooth, app-like feeling on desktop and mobile.
- **Glassmorphism UI**: Premium frosted-glass effects applied to navigation and card elements.
- **Lead Generation Integration**: Call-to-action buttons are directly linked to a Google Form to capture client inquiries seamlessly into a Google Sheet.

## 🛠️ Technology Stack

This project is built focusing on performance and lightweight architecture without the overhead of heavy frameworks:
- **HTML5**: Semantic markup for structure and SEO.
- **CSS3**: Vanilla CSS for styling, utilizing Flexbox, CSS Grid, and custom properties (variables).
- **JavaScript**: Vanilla JS (ES6+) for interactive elements and scroll-triggered animations.
- **Phosphor Icons**: A flexible icon family for modern interfaces.

## 🚀 Getting Started

Since this is a static vanilla web project, there are no dependencies to install or build processes to run.

1. Clone or download the repository.
2. Navigate to the project directory.
3. Open `index.html` directly in any modern web browser (Chrome, Firefox, Safari, Edge).

*Alternatively, you can use a local development server like VS Code's "Live Server" extension for a better development experience with hot-reloading.*
